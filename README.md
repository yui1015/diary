# 日記アプリ

端末内（ブラウザの localStorage）だけで動く、シンプルな日記アプリです。
サーバーやアカウントは不要です。

## できること

- **書く** … 日付・カテゴリタグ・本文を保存
- **カレンダー** … 日付を選んでその日の日記を読む
- **一覧** … 本文・タグで検索して読む／個別ダウンロード
- **すべてDL** … 一覧画面から全日記をテキストで保存

データはこの端末のブラウザにだけ保存されます。

## スマホでの使い方（おすすめ）

同じ Wi-Fi 上の PC から配信し、スマホのブラウザで開きます。

### 1. PC で起動

このフォルダで次を実行します。

```bash
npx --yes serve .
```

表示された URL（例: `http://192.168.x.x:3000`）をメモします。
`localhost` ではなく、**LAN の IP アドレス**の方を使ってください。

### 2. スマホで開く

1. スマホの Safari / Chrome でその URL を開く
2. （任意）ホーム画面に追加するとアプリのように使えます
   - **iPhone**: 共有 → 「ホーム画面に追加」
   - **Android**: メニュー → 「ホーム画面に追加」 / 「アプリをインストール」

オフラインでも、一度開いたあとは Service Worker により使えることがあります。

## 注意

- ブラウザのデータを消すと日記も消えます。大事な記録は一覧の「すべてDL」でバックアップしてください
- `index.html` を直接ダブルクリック（`file://`）でも基本機能は動きますが、PWA（ホーム画面追加・オフライン）はローカルサーバー経由が必要です
